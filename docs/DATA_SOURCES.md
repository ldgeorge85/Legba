# Data sources

A **source** is a declared connector that acquires observations. It owns its own
acquisition: a `SourceActor` turns a `SourceDescriptor` into a running actor that
polls on a cadence or receives a push, produces one canonical, target-agnostic
**signal**, enriches it once, and publishes it once. Signals carry no target —
the fan-out plane routes each one to every subscribing target by predicate, so
one polled feed serves every desk that wants it without re-fetching anything.

This page is for deciding **what to register**: the scope model, the handler
kinds available, the editorial and licence classes a descriptor declares, which
sources need a credential, and how to add one. For how a feed becomes a signal —
the actor, the poll and push protocols, the handler contract, baseline
enrichment, dedup, subscription and the evidence archive — see
[ACQUISITION.md](ACQUISITION.md). Live counts are generated into
[RELEASE_STATE.md](RELEASE_STATE.md) and are never repeated here.

## The scope model

"How many sources?" has three honest answers, because three different things are
being counted. Anchor every scope claim to one of them.

**The out-of-box catalog** is what a bring-up registers with no operator
decisions and no credentials. `deploy/deploy.sh` runs two registrars in order:
`scripts/bringup_register_sources.py`, which registers the **7** pinned
standalone descriptors named in its `SOURCE_FILES` list (three shared global
wires, three state-media voices, one conflict-event feed), and
`scripts/bringup_register_source_catalog.py`, whose `CATALOG` tuple carries
**46** independently-probed, no-auth entries — **43 `rss` plus 3 `geojson`**.
Both are idempotent, so a re-run reports unchanged heads. A fresh deploy
therefore lights up with zero secrets, and nothing in the credentialed tier
active.

The catalog script's own docstring records the feeds that were probed and
deliberately kept out, dead or blocked or discontinued. They are excluded from
the count, and re-probing before re-adding one is the point of the record.

**The in-tree draft batches** are the path past the out-of-box set. The
repository tracks **103** `descriptors/source_*.yaml` files
(`git ls-files 'descriptors/source_*.yaml' | wc -l`), most of them batch
research the operator activates deliberately. Every batch descriptor ships
`state: draft`, which is the safety property that makes bulk registration
harmless: **a draft registers but gets no live actor**, so a batch can land in
the registry whole and still poll nothing until each feed is verified live on the
instance and transitioned `draft → configured → active`. Each batch has its own
idempotent registrar under `scripts/`, which also seeds host-level
`source_credibility` rows with `ON CONFLICT DO NOTHING` so an operator override
or a pre-existing seed always wins.
A batch can also be registered by hand through the same lifecycle route, one descriptor at a time;
the wave-2 feeds were, and they run active with no registrar script behind them.

The descriptors on disk keep reading `draft` after activation, and that is the
intended shape: the repository ships the safe default and the registry's
lifecycle state records the operator's decisions. The live head is authoritative
over the file, always.

**The live scope** is what is actually registered and polling on a given
instance. It is generated by `scripts/generate_release_manifest.py` into
[RELEASE_STATE.md](RELEASE_STATE.md), as a live query against the registry
broken down by kind, and must not be quoted as a literal anywhere else — it moves
with every activation, pause and retirement. Two adjacent numbers are not feeds
and should not be added to it: sources that are paused or retired keep the
signals they already produced, so a count of distinct sources that have ever
emitted exceeds the active-registered count; and autowired per-target fan-out
templates (`src_autowire*` / `src_tmpl*`) are generated bookkeeping, not
upstreams.

### What a batch is for

Batches exist because breadth is a collection decision, not a code change. Two
shapes recur, and both are chosen from a measured gap rather than a hunch:

- **A desk-coverage pass.** A watch-tier desk goes quiet, a read-only count on
  the live signals table confirms no domestic outlet is registered for it, and a
  batch registers the state press agency, a high-volume independent outlet and an
  up-country station for that country.
- **A domain lane.** A thematic desk family needs trade press and primary
  sources — a canal authority, an IGO's trade-measures feed, a semiconductor
  trade title — tagged so the thematic desks' predicates match them.

One batch uses a different mechanism worth naming. Many credible regional,
government and major-media outlets publish no usable feed, so the worst-covered
desks stay thin no matter how many global wires are polled. A self-hosted
**RSSHub** sidecar bridges a chosen outlet route into a standard feed the
existing `rss` handler polls — breadth with no new source kind. The sidecar runs
behind its own compose profile, so a plain `up` never starts it; it is
loopback-bound and memory-capped; and because the `rss` handler's egress guard
blocks internal hosts, activating one of those descriptors also requires the
sidecar on the runtime's egress allowlist. The registrar seeds credibility rows
for the **upstream outlets**, never for the bridge, because the feed's article
links are the real outlet URLs.

## Source kinds

The runtime discovers handlers structurally: it walks `legba.data.sources` and
collects `kind → handler class` pairs from `_SOURCE_MODULE_TABLE`
(`src/legba/runtime/source_factory.py`). **Sixteen** first-party kinds are
registered today, verified against the handlers' own `kind` class-vars
(`grep -c 'kind: ClassVar\[str\]' src/legba/data/sources/*.py`).

Every poll source declares `cadence.schedule` on its descriptor — that is the
tick. The window column below is the handler's own config knob for how far back a
single pull reaches; where it is blank, the handler is purely cursor-driven.
Credential references in config are **vault refs** — a dotted credential id,
never a raw secret — resolved at call time and never cached past one pull.

| Kind | Mode | What it reaches | Window knob | Notes |
|---|---|---|---|---|
| `rss` | poll | any RSS 2.0 / Atom 1.0 feed | — | The broadest surface and the reference handler. Honours conditional GET: stores `(ETag, Last-Modified)` and sends `If-None-Match` / `If-Modified-Since`, so a 304 is an empty pull. No auth. |
| `geojson` | poll | any RFC-7946 GeoJSON document URL | `max_features` | The model-free structured path: emits `structured` / `application/geo+json` signals with geometry inlined and coordinates promoted to the indexed geo column. No extraction model in the loop. |
| `json_api` | poll | any read-only JSON or CSV HTTP API returning an item array | `lookback_minutes`, `max_items_per_pull` | Generic poll counterpart to `generic_webhook`. Cursor-driven `url_template` placeholders for the window; items located by a small dot/bracket path resolver; fields mapped by configurable paths. Auth is fail-loud — a declared `secret_ref` with no resolver raises at configure, activate and pull, and the resolved secret goes in a header or param so the URL stamped into provenance never carries it. |
| `gdelt_files` | poll | the GDELT 2.0 events export, as rolling 15-minute CSV dumps | `lookback_minutes`, `max_files_per_pull`, `max_rows_per_file`, `max_signals_per_pull` | HTTP file fetch, unzip, CSV — no query language, no billing, no rate limit. A different transport from the BigQuery handler, which is why it is a kind rather than a config variant. GDELT is a firehose, so the handler filters hard before emitting. |
| `gdelt_query` | poll | GDELT 2.0 events and GKG via BigQuery | `lookback_minutes`, `max_rows_per_pull` | Pushes country, actor, event-class and tone filters plus a date-partition prune into the storage layer. Cost control is first-class: every pull dry-runs the scan estimate and refuses over the per-pull byte cap, with an optional rolling-day budget. GCP service account. |
| `acled` | poll | ACLED conflict and protest events | `lookback_days`, `page_size` | Needs an API key **and** the registered email for rate-limit attribution. Filters validated against ACLED's own taxonomies at config time. Licence is non-commercial. |
| `ucdp` | poll | the UCDP Georeferenced Event Dataset | `lookback_days`, `max_pages`, `page_size` | One signal per lethal organized-violence event, with coordinates, both conflict sides and fatality estimates; enrichment is geocode-only. Needs a free registration-gated access token sent as a header; with no token resolvable the handler skips the pull entirely rather than producing 401 noise. Data is CC BY 4.0 — attribution required on any re-export. |
| `mediacloud` | poll | the Media Cloud open-news corpus | `lookback_days`, `page_size` | Query-string DSL over collections; uses `httpx` rather than the synchronous upstream client so the actor's event loop never blocks. Rate limits are retried with backoff, then raise. API key. |
| `opensanctions` | poll | sanctions lists, politically-exposed persons, criminal lists | `api_page_size`, `max_bulk_rows` | Three modes: `bulk_csv` (no auth), `api` (key), `self_hosted` (licence-compliant high volume). Entities follow the FollowTheMoney schema, and the controlled topic vocabulary is preserved on the payload for downstream filters. |
| `scraper` | poll | arbitrary sites through a drop-in impl | `max_depth` | The generic crawler owns rate limiting, robots, breadth-first depth and proxying, delegating site-specific discovery and extraction to an impl referenced by dotted path. Optional residential proxy pool as a stack ref. |
| `firecrawl` | poll | arbitrary URLs, as clean markdown | `crawl_limit`, `max_depth` | Distinct from `scraper` in that the LLM-consumable markdown is the product. Mode-dispatched scrape / crawl / map. Emits a credit-usage record per pull for the budget ledger. Paid, credit-based; auth failures are hard and rate limits retryable. |
| `telegram_channel` | poll | public Telegram channels | `lookback_hours`, `per_channel_message_limit`, `max_entries_per_poll` | A user-session MTProto client. Media **metadata only** — bytes are never downloaded here; downstream analysts fan out for transcription or OCR. One descriptor per session is a protocol constraint, not a style choice: a second concurrent client on the same session triggers a session kill. Carries five bounded guards so one slow channel cannot wedge the cycle (see [ACQUISITION.md](ACQUISITION.md)). |
| `common_crawl_news` | poll | the public Common Crawl CC-NEWS archive | `lookback_days`, `max_records_per_run`, `max_warc_files_per_run`, `max_body_bytes` | Anonymous S3 read, no auth. Primarily historical backfill and bulk coverage; each archive file is large, so the runtime re-invokes the pull to continue from the cursor. |
| `intelmq_collector_bridge` | poll | IntelMQ's catalog of collector bots | `max_events_per_pull` | Hooks the collector-to-parser boundary so the CERT-grade collector catalog is reused rather than re-implemented; the full source format is preserved on the payload. Two modes: a one-shot subprocess (needs the optional extra) or draining a Redis destination queue (does not). Heavy optional dependency, imported lazily. |
| `discord_webhook` | push | Discord interactions and messages | — | Every request's Ed25519 signature is verified against the application's public key before any event is emitted; a bad signature raises and the router answers 4xx. Interaction pings are answered without producing a signal. |
| `generic_webhook` | push | any inbound JSON POST | — | The minimal reference push kind, no external dependency. Optional constant-time shared-secret check on a header. |

The factory imports each module defensively, so a missing optional dependency
logs and skips that one kind rather than poisoning the whole registry.

## The source class

Every `SourceDescriptor.scope` carries a **`source_class`**: the source's
editorial class, so the analysis plane can weight a claim by *what kind of source
made it* rather than only by host credibility. The vocabulary is a closed literal
in `src/legba/data/schemas/source.py`, defaulted to the conservative `reporting`
bucket so every descriptor written before the field existed still validates.

| `source_class` | Meaning |
|---|---|
| `reporting` | Straight news and wire reporting — the default, and the "when unsure" bucket |
| `analysis` | Research and data projects, think-tanks, OSINT collectives, coded-event datasets |
| `official` | Government, IGO and primary-source publishers |
| `state_media` | State-controlled outlets, read as **framing** — an official-position signal, low-tier for establishing facts |

Two consumers read it. The `narrative_coordination` unit weighs `state_media` as
framing rather than fact, which is the whole reason state-media feeds are
deliberately ingested rather than excluded: the desk needs to see what a party to
a conflict is claiming. And the hourly salience sweep turns the class into a
signal's deterministic `authority` rank — `official` 4, `reporting` 3, `analysis`
2, `state_media` 1, and 0 for a source with no resolvable class — never
model-chosen. A source reached outside a registered descriptor therefore falls to
the honest authority floor rather than borrowing one. The `collection_gap` analyst uses the
same taxonomy to name which class would plausibly feed a starved desk.

**Per-channel override.** One class per descriptor is the right granularity for a
feed and the wrong one for a descriptor fronting many publishers. A
`telegram_channel` descriptor may therefore carry an optional `config.classes`
map from channel handle to `source_class`, which the salience sweep prefers over
the descriptor's own class. Without it, appending a state outlet to a monitor
classed `reporting` would launder official media into neutral reporting for every
downstream consumer. Three properties keep the map from becoming a second place
for truth to drift: it is choice-locked to the `SourceClass` vocabulary, so an
off-vocabulary value fails at registration; a validator rejects any key that is
not a configured channel, so a typo fails loud instead of quietly overriding
nothing; and handles are normalized identically on both sides, so a match cannot
be missed on formatting.

A related distinction is kept deliberately: state-**funded** but editorially
conventional public broadcasters stay `source_class: reporting` with a
state-affiliation flag on the credibility row. Honest provenance and editorial
independence are two different facts, and collapsing them would mislabel both.

## Licence and robots

Legba fetches what it is allowed to fetch, and says so per host rather than
assuming.

**Licence is a declared field, not an inference.** `SourceScope.license_class` is
a closed literal (`public_domain`, `open_gov_attribution`, `cc_by`, `cc_by_sa`,
`cc_nc`, `open_data_sharealike`, `permissive_feed_unreviewed`, `tos_restrictive`,
`personal_use_only`, `api_terms`, `anti_ai_walled`, `unknown`), defaulting to
`None`. `None` is honest absence — never reviewed — and is deliberately distinct
from `unknown`, which is a reviewed "we looked and could not determine" verdict.
When set, the ingest path copies it onto every signal's payload, where the corpus
facet and the evidence archiver's retention gate read it.

For hosts reached outside a registered descriptor, the same verdict lives on the
per-host **licence ledger**: a `license_class` column on the operator-curated
`source_credibility` table, which is already a per-host, operator-owned ledger
keyed the same way and reviewed by the same person. A second host table would
have given one host two homes and two review surfaces. The column has no check
constraint, because the vocabulary grows with the ledger's review passes and a
constraint would turn every addition into a migration; the vocabulary is enforced
in code instead, and an unrecognised value resolves to the shallowest fetch depth
— the fail-safe direction.

The gate that reads it **fails closed**. A web-origin row whose `license_class`
is unset or `unknown` is not archived: the hit lands as a signal with its
snippet, and no bytes are retained. An affirmative class clears full-text depth
and a content-addressed archive; a refusing class means the page is never fetched
and no row is written at all. The migration that added the column seeds **zero**
verdicts, on purpose: classifying a host is a legal reading, and the platform
will not have a model make one. Until an operator reviews a host, the full-text
path is empty by construction rather than by accident.

**Robots** are obeyed by the one handler that crawls. The `scraper` handler
fetches each host's `/robots.txt` once per host, caches it, and skips any
disallowed URL; `respect_robots` defaults to `True`, the same user agent is used
for the robots fetch and the crawl, and a robots fetch that fails downgrades the
handler's health to degraded rather than silently proceeding as if permitted. The
feed handlers do not crawl — they fetch a published feed URL the publisher
offers for that purpose.

Per-source licence terms that constrain use are recorded where the source is
declared and repeated in the kinds table above: ACLED is non-commercial, UCDP is
CC BY 4.0 with attribution required on re-export, and OpenSanctions' high-volume
path is the self-hosted mode for licence compliance.

## Access class

`SourceScope.access_class` answers a question `license_class` does not: not
*what may we keep of a fetched page*, but **who, inside a Legba deploy, may
read what this source produces once it is in our own substrate.** A single
deploy can carry units or users with very different privileges — or need them
kept apart for research and testing — and this is the mechanism for that, not
enforcement of it yet (see `docs/SEAMS.md` #59). The vocabulary is a closed
literal in `src/legba/data/schemas/source.py` / mirrored in
`src/legba/data/provenance/access.py`, defaulting to the **fail-closed**
`restricted` bucket — never `public` by implicit default, unlike
`source_class`'s conservative-but-open `reporting` default.

| `access_class` | Meaning |
|---|---|
| `public` | No restriction — any unit/user with substrate read access |
| `licensed_commercial` | A paid, commercially-licensed feed — read gated to units covered by that licence |
| `licensed_noncommercial` | Free-for-noncommercial-use — read gated to noncommercial units |
| `restricted` | Reviewed-sensitive, or simply never classified (the fail-closed default) |
| `internal` | Operator-only |

**The classification rule, applied to every committed `source_*.yaml`:**

1. **Default `public`** — a free, no-auth, openly-available feed. No separate
   commercial-licence agreement gates internal read access, so any unit may
   read what it produces. This is the large majority (95 of 103 files),
   including every wire/newspaper RSS feed, every government/IGO primary
   source, every state-media voice, and UCDP GED (CC BY 4.0 is
   attribution-only on re-export — an obligation `license_class` carries, not
   a read restriction).
2. **`licensed_noncommercial`** — a curated dataset carrying its OWN
   noncommercial-bounded reuse terms, distinct from open-web reporting:
   ACLED (non-commercial licence; a paid one is required for commercial
   redistribution) and OpenSanctions bulk + API (default tier CC BY-NC; the
   self-hosted high-volume mode exists specifically for licence compliance).
   Three files.
3. **`restricted` (fail-closed)** — a never-bound generic or template
   adapter with no concrete editorial source to review terms for:
   `common_crawl_news`, `discord_webhook`, `firecrawl`, `generic_webhook`,
   `query_source_discovery_template`. Five files, each a draft binding with
   no live actor (`W1-E` in the taxonomy test) — classified at activation,
   not guessed now.

The per-file verdict is pinned, taxonomy-test style, in
`tests/data_pkg/test_access_class_taxonomy.py::EXPECTED_YAML_ACCESS` — the
same discipline `source_class`'s `EXPECTED_YAML_CLASS` is held to, including
the completeness guard that fails a future `source_*.yaml` landing
unclassified.

**The ingest stamp.** `runtime/source_actor.py:write_canonical_signal` copies
the writing source's `scope.access_class` onto every signal's own
`access_class` column (migration 0216, `NOT NULL DEFAULT 'restricted'`) — the
same shape the LIC-2 `license_class` payload stamp uses, but a first-class
column rather than a payload key. A backfill in the same migration recovers
existing rows from their source's registered head.

**The inheritance rule, rendered but not wired.** A fact/finding/event is as
restricted as the most restricted signal it derives from —
`access_ceiling_sql()` in `data/provenance/access.py` renders that as one SQL
expression (single-hop over `derived_from`, mirroring `origin.py`'s
`live_gate_sql`), for the enforcement side to pick up later. Nothing in this
tree calls it today.

**The opt-in filter.** The `/signals` and `/findings` read routes
(`data/registry/substrate_reads_api.py`) accept `access_class_in=<csv>`.
Absent, every read is byte-identical to before this pass; present, `/signals`
filters its own `access_class` column and `/findings` matches when any
signal in a finding's `derived_from` carries one of the requested classes.
"Accept but never apply by default" is the whole of what this pass builds —
see SEAMS #59 for what is deliberately still missing (a caller identity or
unit to check the filter against).

## Credentialed opt-ins

The out-of-box catalog exercises only the keyless kinds. Everything below needs a
per-deployment secret in the vault before it polls, and each is registered as its
own descriptor rather than through a batch registrar. A fresh deploy has **none**
of them active: an operator opts each one in by provisioning the secret and then
transitioning the descriptor. The in-tree descriptors ship `draft` for exactly
this reason, and their headers carry the flip instructions.

| Opt-in | What it needs | Shape of the commitment |
|---|---|---|
| Telegram | API id, API hash and a session, all vault refs; the session is generated out of band | An account-bound client. One descriptor per session. |
| Firecrawl | API key | Paid and credit-metered; every pull writes a credit-usage record to the budget ledger. |
| MediaCloud | API key | Free tier with rate limits the handler backs off against. |
| Discord | the application's Ed25519 public key | Push — an inbound webhook, verified per request. |
| GDELT via BigQuery | a GCP service account | Scan-billed. The per-pull byte cap and optional daily budget are what keep it bounded. |
| OpenSanctions | none for bulk; an API key for the drill-down mode; a base URL for self-hosted | The bulk mode needs no credential at all. |
| IntelMQ | per-bot configuration, plus infrastructure | Needs an IntelMQ deployment and optionally the Redis bridge, not just a key. |
| ACLED | API key and the registered email | Non-commercial licence; commercial use needs a separate one. |
| UCDP | a free registration-gated access token | Free to obtain; the handler degrades cleanly to no poll without it. |
| Residential proxies | a `proxy_pool` stack component | Optional, and only for the `scraper` kind, which references it as a stack ref and takes an optional proxy country. |

## Adding a source

Registering a source is a deploy-time step, not a code change: the live source
set is the registry's descriptor rows, not the files on disk.

A descriptor is one YAML document with five blocks:

```yaml
identity:                # id, name, kind, schema_uri, version, state, owner, created
  id: source.example.world
  kind: rss
  state: draft           # registers without a live actor; the operator flips it
scope:                   # what target selectors match against
  owner_tenant: shared
  geo: []                # omit for a global feed; a target narrows per signal
  languages: [en]
  tags: [news, world]
  source_class: reporting
  license_class: permissive_feed_unreviewed
acquisition: poll        # or push
cadence:                 # poll only — one poll for the whole platform
  schedule: { factory_kind: cron, raw: "*/15 * * * *" }
  cooldown_seconds: 60
  jitter_seconds: 30
config:                  # validated against the handler's own config_schema
  url: { factory_kind: text, raw: "https://example.org/feed.xml" }
pipeline:                # ingestion filters, baseline enrichment, media policy
  media: reference
```

The descriptor also carries `subscription_policy` (`open` | `allowlist` |
`grant`), which gates who may subscribe to it; see
[ACQUISITION.md](ACQUISITION.md) for how that is enforced.

The lifecycle is the same for every family. Register with
`POST /api/v1/registry/descriptors/{family}`, then move it with
`POST /api/v1/registry/descriptors/source/{id}/transition` through
`draft → configured → active`, pausing and resuming through the same route and
retiring through `/retire`. The Source Registry panel drives all of it from the
console (see [UI.md](UI.md)), and `docs/RUNBOOK.md` has the operator procedure.
Register the feed as `draft`, verify the route live on the instance — a wrong
field path makes a handler emit nothing and report unhealthy, never fabricate —
then activate.

Adding a source needs no code. The existing kinds reach most upstreams, the
predicate fan-out wires the new feed to every desk whose selector matches it, and
nothing downstream is edited.

## Adding a source kind

A kind is a drop-in. There is no central list to edit beyond one table entry.

1. **Write a handler class** in a new module under `src/legba/data/sources/`,
   satisfying the `SourceHandler` protocol from `_contract.py`. Declare the
   class-vars `kind`, `family = "source"`, `schema_version` and `config_schema`.
   There is no base class to inherit — the contract is a runtime-checkable
   protocol, so structural conformance is enough and a handler can be tested
   without a runtime.
2. **Pick a mode.** A poll source implements `pull(ctx, since)` yielding signals;
   a push source implements `ingest(ctx, body, headers)` and sets
   `push_source = True`. Both implement `health_check(ctx)`. A source that must
   register an outbound watch upstream also implements `on_activate` /
   `on_retire`.
3. **Define a pydantic `config_schema`** with `extra="forbid"`. Store credentials
   as vault references and resolve them at pull time; validate filters at config
   time so a bad descriptor fails fast rather than at the first poll.
4. **Yield signals, not enriched rows.** Set the observation-side fields only —
   modality, payload, canonical URL, language hint, and a media *reference* rather
   than bytes — and leave language, geo, tags, entity classes and credibility to
   the baseline. Persist a cursor in the state store, and treat `since` as a
   hint: downstream dedup absorbs the overlap window.
5. **Register the module** by adding one `(module, class)` tuple to
   `_SOURCE_MODULE_TABLE` in `src/legba/runtime/source_factory.py`. The factory
   inspects the constructor signature and threads in only the dependencies the
   handler declares.

Once registered, an operator can author a descriptor of that kind, the actor
schedules it, the baseline enriches its signals and the fan-out routes them — no
other code changes.

## Declared gaps

The authoritative list is [SEAMS.md](SEAMS.md). The acquisition-relevant
entries: `SourceDescriptor.acquisition` documents a third `stream` mode that is
not implemented, only `poll` and `push`; eager media extraction is declared as a
modality-to-extractor registry with thin production handlers, so handlers attach
references and bytes are not fetched; and the per-host licence ledger ships
seeded with no verdicts, so a host stays at teaser depth — snippet landed, no
bytes archived — until an operator reviews it, which is a legal reading the
platform will not have a model make.

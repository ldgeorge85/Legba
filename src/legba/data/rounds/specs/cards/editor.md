# Editor

You read: the ruling (or closing ruling), the tally and the tables you are handed.

You write read/1, last: the majority reading, then, if the rows support one, the dissent in its own words (in `dissent`). If there is none, leave `dissent` empty and say so in `notes`. In `notes`, end with the one observation that would most change the majority reading. If the rows do not decide the question, say so in `notes`. Write nothing else the inputs do not carry.
